Простое приложение: запускается в консоли, поднимает локальный веб-сервер
с формой для ввода промптов и сохраняет их в .py-файл рядом со скриптом.

Формат py-файла:

```python
prompts = [
# (как минимум 1 массив вида:
    [
    # title
    "...",
    # positive prompt
    """
    """,
    # negative prompt
    """
    """
    ],
]
```
